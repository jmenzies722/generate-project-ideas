# Banned and stale ideas

If an idea is a skin of one of these, throw it out and pick another lens.

## Instant reject

- Todo list, habit tracker, notes app, markdown editor
- Weather, world clock, or "personal dashboard"
- Generic chatbot / "ChatGPT UI" / "Claude wrapper"
- AI writing assistant, resume rewriter, email rewriter
- Expense tracker, calorie counter, or generic CRM
- Link-in-bio, URL shortener, pastebin
- Kanban / Jira clone, Notion clone, Slack clone
- "Admin dashboard for my startup"
- Another AI image generator
- Crypto wallet demo, NFT mint page
- "Platform that connects X to Y" with no wedge user

## Soft reject (only allowed with a sharp, unusual wedge)

- Recipe app — only if the wedge is not "save recipes"
- Fitness — only if it is not logging sets
- Budgeting — only if it is not categorizing transactions
- Flashcards — only if learning is interactive and embodied
- Internal chatbot over docs — only if retrieval is not the product
- Agent observability — only if it is not a generic trace viewer

## Smell test

Kill the idea if you cannot finish this sentence honestly:

> A specific person would open this on a Sunday because ________.

Kill it if the demo is "the model answers a question."
That is a feature, not a product.
