# Scoring

Score 1–5. Be stingy with 5s. A 5 means you would start tonight.

## Axes

**Cool** — Would you show this to a sharp friend?
1 = homework, 3 = solid, 5 = they ask for the link

**Pain** — Does a real person already hack around this?
1 = invented, 3 = mild annoyance, 5 = they will switch this week

**Ship** — Can this user ship a credible MVP in the stated timebox
with the stated stack?
1 = research project, 3 = two weekends if focused, 5 = this weekend

**Distinct** — If they described it, would someone say "that's just X"?
1 = clone, 3 = known category with a wedge, 5 = new-feeling combo

## Recommendation rule

Recommend the idea with the highest **Cool × Ship** unless Pain is 1
(kill it) or Distinct is 1 (kill it).

If two ideas tie:

- User wants portfolio / public demo → break toward Cool + Distinct
- User wants work leverage / Shua-style platform → break toward Pain + Ship
- User wants to learn a new surface (3D, mobile, agents) → break toward
  the idea that forces that surface

Write scores you can defend in one clause each. If you cannot defend
a 4 or 5, drop it to a 3.
